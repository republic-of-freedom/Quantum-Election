What the results screen shows

Results that update on their own

The screen reloads each race’s vote file every minute, so a display left open all day stays current.

A race is called by a clear rule

When a candidate passes 450 of the 700 votes, the screen says “Freedom News has called this race” and tags the winner.

Voting turnout and predicted turnout

Two bars are drawn against the full electorate, one for votes counted and one for predicted votes, so you can see how much is still to come.

Made for a big screen

The layout keeps a 16:9 shape and scales to any display, with dark mode by default and a light mode when you want it.
